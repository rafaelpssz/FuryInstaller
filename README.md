# Fury

Instalador do Fury, o painel de staff da FURYWARS.

Baixe o arquivo `Fury-Setup-x.y.z.exe` da versão mais recente em **Releases**.
Na primeira instalação o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações** e depois em **Executar assim mesmo**.

O app se atualiza sozinho depois de instalado.
